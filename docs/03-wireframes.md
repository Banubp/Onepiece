# Responsive Wireframes

## Desktop hierarchy

1. Compact navigation and CV action.
2. Centred editorial hero with the 70×70 Banu mascot above the tagline.
3. Four-case-study asymmetric card field: Nexa, Booking.com, Soft and Onepiece System.
4. Six selected project cards.
5. Work-experience timeline and About/CV block.
6. Contact close with mascot send state.

## Mobile hierarchy

1. Brand and menu control.
2. Positioning copy and primary work action.
3. Mascot retained above the hero tagline at exactly 70×70.
4. Stacked case-study and project blocks.
5. Experience, About/CV, then Contact.

The mascot is itself an accessible button and always stays outside text. It remains 70×70 at every breakpoint.
