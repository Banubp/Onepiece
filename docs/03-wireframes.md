# Responsive Wireframes

## Desktop hierarchy

1. Compact navigation and CV action.
2. Two-column hero: positioning copy plus Banu mascot rail.
3. Alternating Nexa and Booking.com editorial project stories.
4. Practice and capabilities band.
5. About and CV block.
6. Contact close with mascot send state.

## Mobile hierarchy

1. Brand and menu control.
2. Positioning copy and primary work action.
3. Mascot docked to a safe lower-right zone.
4. Stacked project image, story, and action blocks.
5. Practice, About/CV, then Contact.

The mascot always stays outside text and tap targets. On narrow screens it docks to the lower-right safe zone and becomes smaller.
