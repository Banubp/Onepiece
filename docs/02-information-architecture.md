# Information Architecture

## Recruiter scan path

`Hero → Selected work → Role/contribution → Outcome → CV or Contact`

## Design-lead depth path

`Hero → Case study → Problem → Product decisions → Evidence → Reflection → Next project`

## Page sections

| Section | Communication job | Primary action |
|---|---|---|
| Hero | Establish Banu as a product designer for complex systems | View selected work |
| Selected work | Prove product thinking through Nexa and Booking.com | Open project story |
| Practice | Show research, systems, prototyping, and frontend fluency | Inspect capabilities |
| About | Add human context and working style | Download CV |
| Contact | Convert interest into a conversation | Send email |

Persistent compact navigation: Work, Practice, About, Contact, and CV. Era switching is deliberately excluded from the navbar to avoid congestion.
